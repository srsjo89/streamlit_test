# 김영권

데이터 전문기관 파트 담당. 올해는 결합 건이 적어 데이터 제공용 API·FTP 전송 개발을 주로 맡고 있다.

## 담당
- [[데이터-전문기관]] 업무. [[정세원]] 프로와 둘이 별도 파트로 구성. (출처: 김영권 08:58)
- 2026년에는 결합 건이 거의 없어, 데이터 제공을 API·FTP로 자동 전송하는 [[데이터-전송-개발]]을 주로 담당. (출처: 김영권 09:35)
- 서선화 프로님 설명의 "데이터 제공 후 개발 지원 담당, 원래 전문기관 담당"과 같은 사람으로 보고 페이지를 합쳤다. (출처: 서선화 12:04, 김영권 09:35)

## 경력 (업무 판단에 참고)
- 과거 데이터 분석 부서(BDA)에서 오래 근무. 분석, 세그먼트, 마케팅 모델, 추천 알고리즘을 만들었다. (출처: 김영권 01:02, 02:35)
- 실시간 AI 추천 플랫폼 기획 TF에 약 1년 반 참여. (출처: 김영권 02:35, 03:33)
- 데이터 전문기관 라이선스를 받을 때 데이터 사업 쪽으로 옮겨왔고, 그 전후로 마이데이터를 약 1년 담당. (출처: 김영권 01:45)

## 이런 걸 물어보면 된다
- 데이터 결합 절차, 결합 서류(명세서·이행확약서), 결합 비용
- 가명 처리 기법, 원본 처리자·가명 처리자 역할
- API·FTP 전송 개발 절차와 소요기간, [[DLS]]
- 분석·추천 알고리즘 관련 과거 이력
