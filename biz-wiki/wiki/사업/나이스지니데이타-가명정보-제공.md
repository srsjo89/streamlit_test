# 나이스지니데이타 가명정보 제공

나이스지니데이타에 수년간 가명정보를 매월 직접 제공해 온 사업. 2027년에 가맹점 단위 제공으로 바뀔 전망.

## 개요
- 가명정보를 결합전문기관을 거치지 않고 직접 제공. (출처: 서선화 03:53)
- 여러 해 동안 매월 제공해 왔다. 전송일 20일 고정. (출처: 서선화 04:17, 09:16)
- 매월 [[적정성-평가]] 정기 대상. (출처: 서선화 10:03)
- 현재 운영 담당: [[서선화]] (출처: 서선화 03:53)
- 녹취 표기 "나이스진이"는 데이터 중개사 [[나이스지니데이타]]. (출처: 확인필요-답변2 조윤성)

## 수요 배경
상권분석 목적. (출처: 서선화 04:17)

## 제공 데이터와 수준
- 현재: 가명 데이터 (출처: 확인필요-답변2 조윤성)
- 변경 예정: 상권분석 용도라 가명 데이터가 굳이 필요 없어, **가맹점 단위**로 받는 방식으로 바뀔 것으로 예상. (출처: 서선화 04:17)

## 계약·금액
확인필요.

## 이력(회차별)
- ~2026: 가명 데이터 월 제공
- 2027 (예정): 가맹점 단위 제공으로 전환 예상. 전환 시 제공분류와 프로세스가 크게 달라짐.
