# k500 API 제공

법인 사업체 500개에 대한 데이터를 API로 제공하는 건으로 보인다. 녹취가 불명확해 대부분 확인이 필요하다. [확인필요]

## 개요
- 원문 "k500이라고 하는 건가요? 사업체 500개 사업체에 대한 법인 사업체에 대해서 제공하고 커머스 플랫폼 배달 업체에 대해서 제가 개발하는 것을 API를" (출처: 김영권 33:56)
- 해석: 법인 사업체 500곳 관련 데이터를 커머스 플랫폼·배달 업체 등에 API로 제공하는 것으로 추정. [확인필요]

## 제공 데이터와 수준
