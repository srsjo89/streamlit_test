# 데이터 결합 절차

데이터 전문기관에서 두 회사 이상의 가명정보를 결합하고 결과를 내보내기까지의 절차.

## 개요
- 결합 이용 목적은 법상 세 가지(통계 작성, 과학적 연구, 공익적 기록보존)로 한정되며, 실제로는 **대부분 연구**로 되어 있다. 구체적으로 어떤 목적인지 기재해야 한다. (출처: 김영권 17:03; 원문 "통계 작성 기업 구조 대부분의 연구")
- 세 목적의 명칭은 통계 작성, (과학적) 연구, 공익적 기록보존이며, **민간 기관에는 공익적 기록보존이 허용되지 않아** 당사는 통계 작성 또는 연구만 해당한다. 통계 작성에는 상업적 목적이 포함된다. [[개인신용정보-가명-익명-정의]] (출처: 정보보호교육 07:05) [사용자 승인 2026-11-12]
- 결합 전 준비 단계, 결합 단계로 나뉘지만, 실제로는 앞단에서 결합하는 회사끼리 미리 협의해 서류를 만드는 게 대부분이다. (출처: 김영권 21:56)

(출처: 김영권 19:44~23:00)

## 예외와 변형
- 전문기관은 반출 이후에는 크게 관여하지 않는다. 사용 후 2~3개월 뒤 관리 상태를 확인하지 않는다. (출처: 김영권 23:00)
- 정기·반복 결합(2회차 이상, 레이아웃 동일, 기간만 변경)은 평가 비용이 줄어든다. [[결합-비용-구조]] (출처: 김영권 28:55)
- 금융 데이터가 아닌 일반 가명정보 결합은 [[결합전문기관]]에서 한다. (출처: 김영권 14:17)

## 자주 하는 실수
녹취에서 따로 언급되지 않음. 설명자는 "실제로 해보면 어렵지 않고, 필요하면 도와준다"고 함. (출처: 김영권 24:24)

## 당사 내부 전체 프로세스 (정보보호 설명)
위 단계는 전문기관 관점이다. 당사 쪽에서 결합 한 건을 끝내기까지의 단계는 아래와 같다. 보통 원본 처리자, 가명 처리자, 결합정보 분석자가 나눠 맡는다. (출처: 정보보호교육 35:43~38:41) [사용자 승인 2026-11-12]

| 순서 | 단계 | 주의 |
|---|---|---|
| 1 | 정보보호와 사전 협의 | |
| 2 | [[추진품의]] | 원본·가명·익명 처리자, 결합정보 분석자를 **품의에 등록**해야 이후 DB 권한이 승인됨 |
| 3 | 가·익명 시스템 요청서 등록 | 추진품의 후 논리 DB가 있어야 등록 가능 |
| 4 | 계약 품의 | 정보보호팀장 합의 |
| 5 | 요청 건별 논리 DB 권한 신청 (원문 "pidi") [확인필요] | [[가익명-시스템-DB-접근-신청]] |
| 5-1 | (결합) 데이터 전문기관에 결합 신청, 결합 상대방·정보보호 담당·(원문 "신장 담당자") [확인필요]에게 결합키 암호화 일정 협의 요청 | |
| 5-2 | (가명 제공·신용정보 제공·결합) 보안관리약정 체결 | 계약과 함께 감. 모든 건이 정보보호팀장 합의 대상 |
| 6 | 원본 업로드 | |
| 7 | 전문기관 사전 설명회 기초 자료 → 정보보호 검수 → 제출 | |
| 8 | 가명 처리 | |
| 9 | 반출 전 검토 요청 → 정보보호팀이 반출 목적 적정 평가 결과 통보 | 결합 목적 반출은 정보보호팀 자체 평가 [[적정성-평가]] |
| 10 | 데이터 다운로드 | UTF-8, zip 압축이 기본. 다른 형식은 사전 요청 |
| 11 | 25층 격리 PC(전문기관 전용 인터넷 PC)에서 전문기관에 업로드 | [[분석-PC]] |
| 12 | 결합 실사 점검 | |
| 13 | 전문기관 적정성 평가 결과서를 받아 당사 시스템에 업로드 | |
| 14 | 시스템의 가명·원본 데이터, 요청서 모두 파기 → 파기 증서 상신 | |
| 15 | 결합정보를 전문기관 사이트에서 다운로드(25층) → 21층 격리방의 결합정보 분석자 PC에 입력 | 결합정보를 받지 않는 건은 13~14단계에서 끝남 |
| 16 | 분석 종료 → 결합정보 파기 | [[가명결합정보-사후관리]] |

(출처: 정보보호교육 35:43~38:41) [사용자 승인 2026-11-12]

- **순서를 지키지 않으면 다음 단계가 막힌다.** 추진품의를 안 타면 논리 DB를 생성받을 수 없고, 논리 DB가 없으면 요청서에 연결할 DB가 없어 요청서를 등록할 수 없다. (출처: 정보보호교육 39:13~40:01) [사용자 승인 2026-11-12]
- 단계별 상세는 이지인 프로(당시 데이터사업팀)가 작성한 실무 매뉴얼(2025년 말 버전)에 있다. 최신으로 갱신되지 않아 안 맞는 부분이 있을 수 있다. 팀 내에 가진 사람이 없으면 [[강서경]] 프로가 보내주기로 함. [확인필요] (출처: 정보보호교육 35:43, 40:01) [사용자 승인 2026-11-12]
- 결합용 가명정보를 전문기관에 넘길 때는 외부 위원이 참여하는 정기 적정성 평가를 따로 하지 않고, 정보보호팀이 자체적으로 평가(검토)한 뒤 진행한다(설명자는 "따로 하지 않는다"(17:06)와 "정보보호팀에서 자체적으로 한다"(19:36)를 함께 말함 [확인필요]). 전문기관이 가명 처리 적정성을 다시 판단하고, 식별성이 있다고 보면 돌려보내 재처리해야 한다. 결합정보를 받는 회사의 관리 능력도 전문기관이 판단하므로 당사는 관여하지 않는다. (출처: 정보보호교육 17:06~18:02, 19:36) [사용자 승인 2026-11-12]
