# 가익명 시스템 반출 절차

외부로 나가는 데이터는 반드시 [[가익명-시스템]]에 올렸다가 내려받아, 등록된 해시와 일치하는 파일만 내보낸다.

## 개요
외부로 보내려면 데이터를 이 시스템에 올려서 결재를 거친 뒤 내려받아야 하고, 해시가 등록된 파일만 나갈 수 있다. (출처: 서선화 17:51~17:59)

## 단계 (익명정보 기준, 인하대 사례로 설명)
| 순서 | 단계 | 담당 | 산출물·결재 | 소요기간 | 주의 |
|---|---|---|---|---|---|
| 1 | 원본 추출 | 원본 처리자 ([[원본처리자-가명처리자]]) | | | 원칙상 원본 처리자가 뽑고 익명 처리자가 처리하지만, 실무상 추출 시점에 익명 처리까지 해서 뽑음. 원문 "k3로 접근" [확인필요] |
| 2 | 분석 PC에서 프로젝트 전용 DB로 데이터 이동 | 본인 | | | DB 접근 권한 필요 |
| 3 | DB에서 가·익명 시스템으로 업로드 | 본인 | | | **업로드 전에 파일 분할을 끝내야 함** |
| 4 | 처리 담당자가 시스템에서 받아 처리 결재 | 익명(가명) 처리자 | 결재 | | 시스템 처리 기능은 느려서 실제 처리는 Orange에서 함 |
| 5 | 암호화 등 마무리 | 처리자 | | | |
| 6 | [[적정성-평가]] 통과 | 정보보호 | | | |
| 7 | 정보보호 완료 처리 → 내부 결재 → 단계 이동 | 정보보호, 본인 | 결재 | | |
| 8 | 파일 다운로드 → 해시 비교 | 본인 | | | |
| 9 | 데이터 전송 결재 (해시 번호 기재) | 본인 | 결재 | | "이 해시의 파일만 나가겠습니다" |
| 10 | 외부 문서 발송 | 본인 | | | 최대 4GB. [[외부발송-용량과-파일분할]] |

(출처: 서선화 14:57~18:12)

## 예외와 변형
- 가명·가명결합은 단계가 훨씬 더 잘게 나뉘어 있다. 구체적 차이는 설명되지 않음. [확인필요] (출처: 서선화 17:00)
- **롤백**: 잘못되면 앞 단계로 돌아가는데, 돌아가는 것 자체에 결재가 필요하고 앞 단계 담당자에게 다시 작업을 요청해야 한다. 예전에는 롤백 기능이 없어 시스템 업체가 처리해야 했고, 지금은 기능이 추가되었지만 최대한 쓰지 않는 게 좋다. (출처: 서선화 18:34)

## 자주 하는 실수
- 업로드 후에 파일을 쪼갬 → 해시가 달라져 반출 불가 → 롤백. [[외부발송-용량과-파일분할]]
- 쿼리 결과나 레코드 수를 증적으로 캡처할 때 **쿼리와 결과를 떼지 않고 한 장으로** 캡처하지 않음 → 이 결과가 이 쿼리의 결과라는 증명이 안 됨. (출처: 정보보호교육 30:06) [사용자 승인 2026-11-12]
- 다운로드 형식은 UTF-8과 zip 압축이 기본이다. 다른 방식이 필요하면 **사전에 요청**하지 않으면 이 형식으로만 만들어진다. (출처: 정보보호교육 36:52) [사용자 승인 2026-11-12]
