## 예외와 변형
- **분류별 품의·전결**: 가명·가명결합은 [[추진품의]]에 CISO 합의가 거의 필요하다. 기타는 추진품의가 필요 없지만 **정보보호 합의는 거친다**. 절차는 가명·익명보다 단순하다. (출처: 확인필요-답변2 조윤성) CISO인지 정보보호팀장인지 등 레벨은 분류에 따라 다르니 건마다 확인한다. (출처: 서선화 06:44~07:25)
- **단계별 정보보호 결재선 (2026-11-12 설명)**: (출처: 정보보호교육 25:35, 30:06~31:18, 35:43) [사용자 승인 2026-11-12]

| 단계 | 정보보호 쪽 합의·결재 |
|---|---|
| 추진품의 (가명·익명) | CISO([[손영설]]) 합의. 결재 레벨 관련 원문은 불명확 [확인필요] (익명 건 CISO 합의는 서선화 설명과 상충 가능 → [[추진품의]]) |
| 계약 품의 | 정보보호팀장 합의 (필수), 정보보호팀 담당자에게 통보 |
| 보안관리약정 (가명 제공·신용정보 제공·결합) | 정보보호팀장 합의. 계약과 함께 감 |
| 가·익명 시스템 요청서 등록 | 정보보호 담당([[강서경]]) 합의. 결재 경로는 시스템에 자동 반영되어 있어 확인만 하면 됨 |
| 사전 데이터셋 등록 → 사전 검토 → 평가 자료 → 적정성 평가 요청 | 정보보호팀장 합의 |
| 적정성 평가 결과 보고 | CISO 결재로 확정 |
| 반출 요청(데이터셋 전송 요청, 외부 제공 요청) | 정보보호팀 담당자 합의 |

- 비결합 건은 비교적 간단하고, 결합 건은 훨씬 복잡하다. 현업은 다른 회사보다 절차가 복잡하다고 말한다. [[데이터-결합-절차]] (출처: 정보보호교육 30:06, 31:18) [사용자 승인 2026-11-12]
- **가명 직접 제공**: 셋업 시 보안 담당자의 고객사 실사 등으로 1년 넘게 걸린 사례가 있다. [[신세계-가명정보-제공]] (출처: 서선화 04:17)
- **CB와 협업하는 건**: 신용정보이므로 검토 기준과 전결이 달라진다. [[CB는-다른-회사로-간주]] (출처: 서선화 24:32)
