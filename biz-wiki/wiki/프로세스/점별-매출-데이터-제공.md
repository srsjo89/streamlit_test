# 점별 매출 데이터 제공

가맹점별 매출(당사 매출 + 추정매출)을 고객에게 내보내는 절차. 2026년 4월부터 공식화됐고, 반드시 사내 CB 파트를 거친다. 고객 반응이 가장 좋은 데이터다.

## 개요
- 점별 데이터에 대한 고객 반응이 가장 좋다. 이 데이터가 풀리면서 사업 상황이 크게 커졌다. (출처: 사업설명 24:39~24:54)
- 근거 라이선스: [[기업정보조회업]]. CB 파트가 최종 제공 주체. (출처: 사업설명 27:56)

## 공식화 경위
| 시점 | 내용 |
|---|---|
| 2025-10 | 기업정보조회업 취득. 그러나 정보보호가 매출 원데이터 제공을 막음 |
| 2026-01 | 네이버파이낸셜에 점별 데이터 제공. 공식화 전이라 실매출 대신 지수 형태로 제공 [[네이버파이낸셜-점별-데이터]] |
| 2026 초 | 금융위원회 유권해석: 신용정보법 라이선스 보유 기관은 신용정보법 기준 적용 가능 |
| 2026-03 | 추정매출 제공 허용 |
| 2026-04 | 가맹점별 당사 매출 제공까지 허용 → 공식적으로 점별 당사 매출 + 추정매출 제공 가능 |
(출처: 사업설명 25:01~27:56, 최원재 27:48~28:57)

## 단계
| 순서 | 단계 | 담당 | 산출물·결재 | 소요기간 | 주의 |
|---|---|---|---|---|---|
| 1 | 가맹점 단위 키로 사업팀이 줄 수 있는 모든 속성을 채운 데이터셋 작성. **추정매출과 당사 매출 칸은 비워 둠** | 사업팀 | 데이터셋 | | 가맹점별 매출 비중 등 계산까지 사업팀이 함 |
| 2 | CB 파트에 전달 | 사업팀 | 결재, 정보보호 확인 | | 외부 회사에 주는 것과 같은 절차 [[CB는-다른-회사로-간주]] |
| 3 | 추정매출·당사 매출을 키로 조인해 붙임 | CB 파트 | | | |
| 4 | 고객에게 최종 제공 | CB 파트 | | | |
(출처: 사업설명 27:56~28:42)

## 예외와 변형
- 사업팀도 기술적으로 추정매출을 볼 수는 있으나 공식적으로는 쓰지 않는다. (출처: 사업설명 28:45~28:50)

## 자주 하는 실수
- 절차가 한 단계 늘어 번거롭지만 상황상 반드시 이렇게 해야 한다. 사업팀이 직접 매출을 붙여 내보내지 않는다. (출처: 사업설명 28:23)
