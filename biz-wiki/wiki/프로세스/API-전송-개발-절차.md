# API 전송 개발 절차

데이터 제공을 API·FTP 자동 전송으로 개발하는 절차. 업체와 미리 협의하고 체크리스트를 따른다.

## 개요
진행하려면 업체와 미리 협의해야 하고, 건별 체크리스트가 팀 자료에 정리되어 있다. (출처: 김영권 31:51~33:05)

## 예외와 변형
- 신규 API: 테이블부터 만들어야 해서 보통 **한 달**, 빠르면 2~3주. (출처: 김영권 37:08)
- 기존 테이블 등을 활용하면 빠르면 **2주**. (출처: 김영권 37:08)
- 요건 변경: 사소한 것도 이관 절차를 다시 밟아 **약 1주**. 긴급 건은 예외 가능. (출처: 김영권 35:23)

## 자주 하는 실수
- 요건 오타(예: A와 B를 잘못 씀)를 나중에 고치려 해도 1주가 걸린다 → 요건 정의 단계에서 꼼꼼히 확인. (출처: 김영권 35:23)
