# 가익명 시스템 DB 접근 신청

프로젝트가 생기면 [[가익명-시스템]]에서 프로젝트 전용 DB를 받고 접근 권한을 신청하는 절차.

## 개요
- DB는 마음대로 만드는 것이 아니라 프로젝트가 생기면 담당자에게 번호를 받는다. (출처: 서선화 19:16)
- **[[추진품의]]가 완료되어야** 계정 발급이 가능하다. (출처: 서선화 20:53)
- 사전 준비: 가·익명 시스템 권한, 방화벽 신청. (출처: 서선화 14:57)
- 시스템 매뉴얼이 잘 되어 있으니 매뉴얼을 따른다. 매뉴얼은 설명자가 별도로 전달함. (출처: 서선화 18:34~19:16)

## 단계
| 순서 | 단계 | 담당 | 산출물·결재 | 소요기간 | 주의 |
|---|---|---|---|---|---|
| 1 | DB 번호 생성 요청 | 본인 → DB 담당 프로 (원문 "세 번째 프로", "회원제 프로". "회원제"는 [[최원재]] 프로와 발음이 비슷해 후보로 봄) [확인필요] | DB 번호 | | |
| 2 | DB 번호로 계정 신청 | 본인 | | | |
| 3 | 샤크라 비밀번호 수령 → 입력해 계정 생성 | 시스템 담당자 | 계정 | | 비밀번호는 위키에 기록하지 않음 |
| 4 | 해당 DB 접근 권한 결재 | 본인 | 결재 | | |
| 5 | 접근 | 본인 | | | [[샤크라]]를 통해서만 접속 가능 |
| 6 | 프로젝트 신청 → 단계별 권한 지정 | 본인 | | | 역할(원본·가명·익명 처리자)별로 할 수 있는 단계가 정해짐 |
| 7 | 프로젝트 종료 시 접근 권한 삭제 → 정보보호 담당에 통보 | 본인 | 통보 | | [[접근권한-회수-통보]] |

(출처: 서선화 15:53, 19:16~20:11)

## 예외와 변형
- 처음 로그인하면 아무것도 보이지 않는다. 본인이 담당하는 프로젝트만 보이기 때문이다. (출처: 서선화 14:57)
- 데이터 작업은 별도 **분석 PC**에서만 가능하다. (출처: 서선화 15:53)
- **역할별 DB 권한 (정보보호 설명)**: 원본 처리자는 PDW 권한(원문 "운번 처리자는 pad w"), 가명 처리자는 PPI ID 권한, 결합정보 분석자는 PPI DC 권한을 신청한다. 권한 이름은 STT가 불명확해 [확인필요]. (출처: 정보보호교육 26:37) [사용자 승인 2026-11-12]
- 요청 건마다 개별 논리 DB를 받으며, 정보보호가 매달 그 접근 권한이 추진품의에 적힌 역할과 맞게 부여됐는지 점검한다. [[접근권한-회수-통보]] (출처: 정보보호교육 33:32) [사용자 승인 2026-11-12]
- 결합정보 분석 DB 권한을 신청할 때는 본인 정보계 접근을 잠그는 신청 품의 문서를 함께 보내야 승인된다. [[가명결합정보-사후관리]] (출처: 정보보호교육 27:44) [사용자 승인 2026-11-12]

## 자주 하는 실수
