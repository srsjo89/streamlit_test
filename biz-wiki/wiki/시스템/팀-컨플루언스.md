# 팀 컨플루언스

팀 업무 자료와 미팅 이력이 쌓이는 Confluence 공간. 팀장 표현으로 "모든 히스토리가 다 나와 있다". 원문 "컨퍼런스", "컴플", "컨플"은 모두 이것. (출처: 팀장OJT 13:03)

## 용도
팀 공간 안에 업무별 자료가 있다. (출처: 김영권 06:45)

## 접속과 권한 신청
확인필요.

## 주요 기능 (확인된 페이지)
- "데이터 전문기관" 공간: 진행 상황, 지금까지 진행한 결합 목록(62번까지), 매뉴얼 (출처: 김영권 06:45, 13:04)
- 정산 관련 자료, 결합 건별 일정·비용 조항 (출처: 김영권 31:51)
- API 자동 전송 개발 목록과 체크리스트 (출처: 김영권 31:51~33:05)

## 실제 사용 방식
- 2022년 말 도입. 적응이 힘들다던 경력사원(SKT 출신)의 제안에서 시작됐다. 미래사업부문에서 먼저 활성화. (출처: 팀장OJT 14:14~15:18)
- 강상현 팀장 시절부터 사이트 미팅 이력을 남기는 문화를 만들었고, 기록을 다시 꺼내 쓰는 효과가 체감되면서 정착. 별도 보고자료 대신 컨플루언스로 보고하기도 한다. (출처: 팀장OJT 13:28)
- 다른 팀 글도 피드로 보인다. 팀마다 활용 깊이가 다르고, 영업 조직은 엑셀 위주라 거의 쓰지 않는다. (출처: 팀장OJT 15:18~16:23)
- 개인 페이지도 만들 수 있으나 공유 접근성은 떨어진다. (출처: 팀장OJT 16:35)
- 업체 공간 첫 페이지에 소개 경로를 적는다. [[사업-이력-기록]] (출처: 사업설명 07:41)
- KPI 관리판·판매 리스트가 매월 올라온다. [[팀-사무국-KPI-관리]] (출처: 최원재 10:15)
- 솔루션팀 자료도 이곳에 추가될 예정. (출처: 이하나 25:05)

## 주의점
이 위키에 넣을 원본 자료가 많은 곳이다. 우선 결합 이력 목록, 가격표, API 개발 체크리스트를 raw/로 가져오는 것을 권장.
