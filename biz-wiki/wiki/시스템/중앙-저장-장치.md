# 중앙 저장 장치

사내 파일 저장소. 개인함은 약 3GB이고, 팀은 부서함을 쓰지 않는다.

## 용도
개인·프로젝트 파일 저장소.

## 접속과 권한 신청
- 접속 주소는 위키에 기록하지 않는다(규칙서 9장). 팀장 OJT 메모 참고.
- 혁신실 중앙 저장 장치 권한은 원문 "원지"에게 요청 [확인필요]. (출처: 팀장OJT 03:41)
- 내 아이디로 로그인한 PC에서는 어디서나 내 개인함이 보인다. (출처: 팀장OJT 07:18)

## 주요 기능
- 개인함: 약 3GB. (출처: 팀장OJT 06:04)
- 부서함·프로젝트함: 권한 통제. 부서함을 쓰는 부서는 거의 없고 우리 팀도 안 씀. (출처: 팀장OJT 03:41, 06:04)
- 공개 자료함: 읽기만 가능. (출처: 팀장OJT 06:04)

## 실제 사용 방식
C 드라이브 대신 여기에 업무 파일을 두는 이유는 [[PC-개인정보-검사]] 참고.
