# 분석 PC

정보계 데이터를 다루는 별도 PC. 파이썬으로 바로 붙을 수 없어 대부분 SQL 기반으로 작업한다.

## 용도
정보계 데이터 분석 전용 PC.

## 접속과 권한 신청
- 세팅 필요(합류 직후 해야 할 일). (출처: 팀장OJT 01:42)
- 가·익명 시스템 데이터 작업도 별도 분석 PC에서만 가능. (출처: 서선화 15:53)

## 주요 기능
- 접근 가능 영역: 정보계. (출처: 팀장OJT 21:42)

## 실제 사용 방식
- 파이썬으로 쓰려면 해당 DB 계정에 select 권한을 받고 필요한 테이블을 이관해야 한다. 양이 많아 시간이 오래 걸려 **파이썬 작업은 거의 하지 않는다**. (출처: 팀장OJT 22:06~22:39)

## 주의점
- **물리 환경 (정보보호 설명)**: (출처: 정보보호교육 27:44~28:54, 36:52~37:36) [사용자 승인 2026-11-12]
  - 서버용 PC: 가·익명 처리용 서버 DB(원문 "PDW")에 접근. 테이블 생성·삭제(create·drop)도 팀장 품의를 받아야 해서 쿼리 작업이 불편하다.
  - 업무용 PC: 정보계에 접근. 서버용 PC와 같은 자리에 함께 있다.
  - 가명정보·결합정보는 격리방에서만 작업한다. 결합정보 분석자 PC는 21층 격리방에 있다.
  - 25층에는 데이터 전문기관, 신세계 AWS, 나이스지니데이타 AWS에만 접근 가능한 인터넷 전용 격리 PC가 있다. 결합용 데이터 업로드와 결합정보 다운로드를 여기서 한다.
- 결합정보 작업 중 누락이 생겨도 정보계 grant로 채우지 않는다. [[가명결합정보-사후관리]] (출처: 정보보호교육 28:54) [사용자 승인 2026-11-12]
