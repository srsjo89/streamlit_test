# 데이터 전송 개발

반복적으로 나가는 제공 데이터를 매번 수작업하지 않도록 API나 FTP 자동 전송을 개발하는 업무.

## 개요
- 계약 후 월 단위 등으로 **같은 레이아웃**을 반복 전달할 때, 수작업 대신 API를 개발해 제공하거나, 용량이 크면 파일을 쌓아주는 방식(원문 "웹 기로" [확인필요])으로 개발한다. (출처: 김영권 33:05)
- 데이터 외부제공 프로세스에서 "데이터 제공 후 개발이 필요하면" 이어지는 단계다. (출처: 서선화 12:04)

## 배경과 히스토리
2026년에는 결합 건이 적어 데이터 전문기관 담당자가 이 업무를 주로 맡았다. (출처: 김영권 09:35)
- 수작업을 줄이려고 API 전송을 2025년부터 시작. (출처: 최원재 27:48)

## 규모와 숫자
