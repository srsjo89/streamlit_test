# 팀 사무국 KPI 관리

담당 단위의 KPI·임원 평가 관리와 각종 보고자료 대응을 맡는 사무국 업무. 데이터사업 담당은 [[최원재]] 프로 혼자 한다.

## 개요
- 주 업무: KPI 관리, 임원 평가 관리, 전략회의 등 보고자료 작성·제출. (출처: 최원재 03:24)
- 경영지원팀·38층 금융 TF 등에서 오는 자료 요청을 대응한다. (출처: 최원재 02:00)
- 다른 본부(마케팅, 카드사업 등)는 팀 하나가 통째로 사무국 역할을 한다. 데이터사업 담당은 회사 메인 사업에서 비켜나 있어 1명으로 충분. (출처: 최원재 00:28~01:27)

## 배경과 히스토리
- 최원재 프로는 2023년 팀 합류, 2023~2024년 실무, 2025년부터 사무국. 이전 업무 중 연 1회 수준의 결합 건(원문 "문화정보원" 등)은 계속 맡고 있다. (출처: 최원재 03:24)

## 규모와 숫자
### 상무 업적 평가 항목 (2026, 약 8개)
| 항목 | 내용 |
|---|---|
| 데이터 매출 | 광고 40억 / 데이터 60억 |
| CB 라이선스 매출 | CB 관련 매출 별도 목표 |
| 판매 계약 업체 수 | |
| 임베디드 솔루션 판매 수 | |
| 신규 서비스 | 지역 축제 4건 목표 → 1건 예상 [[지역축제-데이터]] |
| 지수·모형 고도화 | 데이터랩 생활경제맵 지수 등 개수 |
| 데이터톡 | 월 1건 [[데이터톡]] |
- 2025년 65점 만점에 62점. 다만 점수보다 정성 평가(잘한 것·못한 것 서술)가 중요하다. (출처: 최원재 16:19~19:04)
- 부문장 평가에서 데이터사업 비중은 작다(모니모 원앱 통합, AI 등 비중이 큼). (출처: 최원재 19:04)

## 담당과 역할 분담
- 주간 보고: 팀장, 최원재, 파트 리더 참석. (출처: 최원재 08:34)
- 솔루션팀 임베디드·CB는 실적 관리만. (출처: 최원재 08:46)

## 주요 프로세스
### 월 마감
- KPI 관리판과 판매 건 리스트, 예산 건(영업 중) 리스트를 매월 마감해 컨플루언스에 올린다. 메일로 따로 공유하지 않는다. 상무는 판매 리스트로 주로 본다. 연말까지 관리판을 정리할 예정. (출처: 최원재 07:28, 10:15)
### 경영계획 보고
- 경영지원팀 주관으로 회사 경영계획을 짠 뒤, 사장 컨펌으로 끝나지 않고 [[금융경쟁력제고TF]]의 컨펌을 받는다(손익, 마케팅 등). 10월 중순 보고. (출처: 최원재 21:54)
- 각 사업부가 참고자료를 낸다. 회사가 선호하는 워드 양식(바탕체 등)이 있다. 2027년 데이터사업 참고자료는 두 꼭지: ① 라이선스 기반 수요처 발굴·신규 사업, ② AI(합성 소비자, AI 플랫폼). (출처: 최원재 21:54~23:26)
### 전략회의
- 매년 12월·6월 전사 임원 전략회의. 2025년 12월(2026년 전략) 회의에는 데이터사업이 아젠다에 없었다. 보고 자료를 만들었으나 부문장 보고는 이뤄지지 않음. (출처: 최원재 23:40~25:14)
