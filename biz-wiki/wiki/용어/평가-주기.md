# 평가 주기

회사의 평가 리듬. 조직·개인은 12~5월, 6~11월로 나뉘고, 임원은 1~10월 실적으로 평가한다. 성과를 언제 내느냐가 중요하다.

## 정의
| 대상 | 기간 | 비고 |
|---|---|---|
| 조직·개인 상반기 | 12월 ~ 5월 | 12월 초 임원 인사 후 새해 리듬 시작 |
| 조직·개인 하반기 | 6월 ~ 11월 | |
| 영업 조직 | 위보다 한 달 빠름 | 10월 마감 후 평가, 11월부터 새 평가 기간 |
| 임원 | **1월 ~ 10월 실적** | 11월 중 평가 완료, 다음 해 거취 결정 |
| 개인 평가 구성 | 상·하반기 업적 고과 + 연 1회 역량 평가 = 연 3회 | |

(출처: 최원재 14:32~15:00, 팀장OJT 25:03~27:33)

## 헷갈리는 점
- 임원 평가가 10월에 끝나서, 11월부터는 회사 전반의 실적 긴장도가 떨어진다. LMS도 10월까지를 집중 기간으로 본다. [[LMS-광고]] (출처: 황성환 06:59)
- 개인 평가 기간(12~5, 6~11)과 임원 평가 기간(1~10)이 다르다.

## 사용 예 (팀장 팁)
- 성과를 드러내기 좋은 시기: **4월 말~5월 초**, **10월 말~11월 초**. (출처: 팀장OJT 27:10)
- 상반기에 시작한 일은 5월 말까지 마무리한다. 하반기라면 6~8월에 달리고 9월에 방점을 찍는다. 애매하게 7~8월에 끝내거나 12월에 하면 기억되지 않는다. (출처: 팀장OJT 25:03~27:10)
