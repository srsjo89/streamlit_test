# 결합전문기관

가명정보끼리 결합하는 일반 기관. 금융회사가 끼는 결합은 여기가 아니라 [[데이터-전문기관]]에서 해야 한다.

## 정의
- 가명 데이터를 서로 결합하는 기관. 개인정보에 해당하므로 개인정보보호위원회 소관. (출처: 김영권 14:17; 원문 "개도 위 소고관" — 개인정보보호위원회로 해석 [확인필요])

## 헷갈리는 점
| | 결합전문기관 | 데이터 전문기관 |
|---|---|---|
| 소관 | 개인정보보호위원회 | [[금융위원회]] |
| 대상 | 일반 가명정보 결합 | 결합 주체 중 한 곳이라도 금융회사일 때 |
| 당사 | 해당 없음 | 당사가 지정 기관 |
(출처: 김영권 14:17)

- [[신세계-가명정보-제공]], [[나이스지니데이타-가명정보-제공]]은 결합전문기관을 거치지 않고 가명정보를 직접 보내는 예외적 방식이다. (출처: 서선화 03:53)

## 사용 예
"가명 데이터를 서로 결합하는 거는 그냥 결합 전문 기관인데... 금융 데이터에 대해서는 데이터 전문기관에서" (출처: 김영권 14:17)
