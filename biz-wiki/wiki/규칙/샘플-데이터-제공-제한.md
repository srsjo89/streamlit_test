# 샘플 데이터 제공 제한

계약 전 고객에게 실제 데이터 샘플을 파일로 내보내는 것은 원칙적으로 금지다. 영업에서 가장 자주 부딪히는 약점이다.

## 규칙
계약 전에는 실데이터 샘플 파일을 외부로 보내지 않는다. 보여줄 수 있는 것은 극히 일부 집계값 수준으로 제한한다.

## 이유
- 법무에서 샘플 데이터 외부 제공을 공식적으로 금지했다. 이 문제를 공론화했다가 오히려 더 엄격해졌다. (출처: 사업설명 13:15, 15:18)
- 고객은 상대의 샘플을 봐야 구매를 결정하므로 영업상 약점이 된다. (출처: 사업설명 13:17)

## 어기면 생기는 일
회사 규정 위반. 보낸 사람이 책임진다. (출처: 사업설명 15:00)

## 구체적인 방법
| 고객 요청 | 가능한 대응 |
|---|---|
| 실제 볼륨·숫자 규모 | 집계 수치를 메일 본문에 붙이는 수준 (출처: 사업설명 13:54, 14:56) |
| 데이터 형태·유효값 확인 | 가짜 데이터를 만들어 형태만 보여줌. 10~20줄 수준, 수천 줄은 불가 (출처: 사업설명 13:54~14:12) |
| 고객이 직접 집계표 양식을 준 경우 | 집계값만 채워서 (예: 부산 전통시장 분기별 금액) (출처: 사업설명 14:32) |
| 백테스트용 과거 데이터 | 데이터를 사는 계약으로 진행 (기본 계약에 덧붙이거나 새 계약) (출처: 사업설명 13:22~13:42) |

- 현대홈쇼핑 제안 때 샘플을 출력물로만 보여주고 회수했는데, 고객이 파일 보고가 안 된다는 점을 불편해했다. [[현대홈쇼핑-제안]] (출처: 사업설명 12:24)
