# 사용 제한 데이터

회사가 가진 데이터라도 모두 팔 수 있는 것은 아니다. 동의 여부, 수집 목적, 법 저촉 여부를 따져야 하며, 아래 데이터는 특히 주의한다.

## 규칙
데이터를 제공하기 전에 그 데이터가 고객 동의를 받은 것인지, 원래 수집 목적이 판매·가공을 허용하는지 확인한다. 아래 데이터는 사용 전에 반드시 팀장과 확인한다.

## 이유
- 전국 데이터를 가지고 있다고 다 팔 수 있는 게 아니다. 동의가 있는 데이터인지까지 따져 정보보호와 협의한다. (출처: 사업설명 16:56~17:09)

## 어기면 생기는 일
법 위반, 감사 지적.

## 구체적인 방법
| 데이터 | 상태 | 근거 |
|---|---|---|
| 대중교통 승하차 데이터 | **사용 불가**. 고객 동의가 없고 위치정보법 저촉 판단을 받은 적이 있어 테이블 접근을 막았다. 감사팀 등 일부만 접근 | 사업설명 17:38~18:19 |
| 외부 기관 데이터(교통카드사 등) 활용 | 원천 기관의 공문 승인이 있어야 당사 책임으로 사용. 공문이 없는 곳 데이터는 불가 | 사업설명 18:19~18:55 |
| VAN사 데이터 | 원래 내부 시장점유율 확인 목적의 계약이라, 데이터 판매의 **공식 근거로 쓰기 어려운 상태**. 정확도는 매우 높다. 공식 추정매출 원천은 [[KCB-컨소시엄-매출]] | 사업설명 01:44~02:30, 29:09 |
| PG사 품목 정보 | 원래 거래 상호 확인 목적이라 가공·판매는 법무상 불가 판단이 나올 가능성 | 사업설명 19:01 |

- VAN사 데이터 추가 정보: 2026-11-03 네이버페이 미팅에서 당사는 전체 매출 추정 방식을 설명하며 "당사도 자체 보유 VAN사 정보로 삼성카드 단독 스케일 추정을 제공하는 것이 있다"고 소개했다. 또 [[나이스지니데이타]]는 VAN사 정보로 지역별 카드사 점유를 보고 3개 카드사 데이터를 스케일하는 방식이라고 설명했다. [[KCB-컨소시엄-매출]] (출처: 네이버페이미팅 1:03:24) [사용자 승인 2026-11-05]

> ⚠️ 상충: 위 표는 VAN사 데이터를 "데이터 판매의 공식 근거로 쓰기 어려운 상태"(출처: 사업설명 01:44~02:30)로 적고 있으나, 2026-11-03 외부 미팅에서는 VAN사 정보 기반 당사 단독 추정을 제공 방식의 하나로 소개했다(출처: 네이버페이미팅 1:03:24). 두 내용을 모두 남긴다. 현재 VAN사 데이터 기반 제공의 공식 근거 상태는 확인필요. [사용자 승인 2026-11-05]

- 판단이 애매하면 정보보호에 명세와 필요 이유를 모두 밝히고, 사업팀이 먼저 가능 여부 안을 만들어 협의한다. [[정보보호팀]] (출처: 사업설명 17:09)
