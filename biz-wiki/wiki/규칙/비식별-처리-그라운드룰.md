# 비식별 처리 그라운드룰

비식별 처리에는 정해진 일률적 규칙이 없고 건별로 협의하지만, 최소한으로 지켜야 하는 기본 기준(그라운드룰) 문서가 있다.

## 규칙
비식별 강도는 건별로 정보보호와 협의하되, 그라운드룰의 최소 기준 아래로 내려가지 않는다.

## 이유
비식별 강도는 여러 요소를 종합해 판단하기 때문에 일반 규칙이 없다. (출처: 서선화 20:53~21:39)
- 데이터 크기와 대상
- 다른 카드사 데이터와 합쳐지는지, 단독으로 나가는지
- 공개 범위: 대회 등으로 개방되는지, 학술 연구 목적인지
- 목적과 내용

## 최소 기준 (녹취에서 언급된 예)
- 사람 기준 k=5 적용 (원문 "케이스 5") — 아래 정보보호 설명에서 회원 기준 최소값이 k5로 확인됨
- 건수 기준도 별도 기준 적용 (값은 녹취에서 불명확) [확인필요]
- 랜덤 샘플링, 아웃라이어 처리 기준 있음
- 완전 대중 공개(정부 플랫폼 등재 등)는 k=20이 최소
(출처: 서선화 21:39)

## 정보보호 설명 기준 (2026-11-12)
| 대상 | 기준 |
|---|---|
| 회원 | 회원 준식별자 기준. k5 / k10 / k20 중 적용 (원문 "k5 k1 k 20", k10 여부 [확인필요]). **k5보다 낮은 건 없다** |
| 회원, 특정 민간 기업이 매우 제한적으로 사용 | 최솟값 적용 (원문 "KO 최소예요", k5로 추정 [확인필요]) |
| 회원, 대학·중소기업 제공 + 제한적으로라도 인터넷 어딘가에 공개 (두 조건이 "그리고"인지 "또는"인지 [확인필요]) | **k20이 그라운드룰** |
| 가맹점 | 가맹점 준식별자 기준으로 계산 |
| 건수가 나가는 경우 | 가맹점·회원 조건을 다 걸어 건수 기준 이상 등 **3개 조건을 반드시 충족** (원문 불명확, 조건 내용 [확인필요]) |
| 기타정보 | 회원 (원문 "kc") [확인필요], **가맹점 k5 이상**이 가이드라인. 익명보다 통계 수준으로 더 뭉갬 |

(출처: 정보보호교육 21:33~22:48) [사용자 승인 2026-11-12]

- 주기적·반복적 제공 건은 샘플링 필수(3분의 2 이하). [[시계열-제공-샘플링]] (출처: 정보보호교육 22:48) [사용자 승인 2026-11-12]
