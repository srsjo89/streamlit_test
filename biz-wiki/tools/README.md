# tools

위키 관리용 스크립트. 표준 파이썬만 쓰므로 별도 설치가 필요 없다. `biz-wiki/` 폴더에서 실행한다.

| 명령 | 하는 일 | 언제 |
|---|---|---|
| `python tools/build_index.py` | 페이지 라벨과 첫 요약 줄로 `wiki/index.md`를 다시 만든다 | ingest 끝날 때마다 |
| `python tools/lint.py --fix` | 한쪽 방향 링크를 자동 보완하고, 끊긴 링크·고아·중복 후보·유통기한·상충을 보고 | ingest 끝날 때마다 (기계 점검) |
| `python tools/metrics.py --label 이름 --save` | 구조 지표를 계산해 `metrics_history.csv`에 한 줄 추가 | ingest 끝날 때마다 |

## 구조 지표 읽는 법
출처 페이지와 index·log·확인필요는 빼고 계산한다.

| 지표 | 뜻 | 좋은 방향 |
|---|---|---|
| 평균연결수 | 페이지 하나가 연결된 다른 페이지 수 | 5 이상 유지 |
| 약연결비율 | 연결이 2개 이하인 외톨이 페이지 비율 | 낮을수록 |
| 최대허브점유 | 가장 큰 허브 페이지가 전체의 몇 %와 연결되는지 | 0.5 넘으면 허브 분할 검토 |
| 섬개수 | 링크로 이어지지 않는 덩어리 수 | 업무가 정말 분리된 경우 외엔 1 |
| 교차출처비율 | 원본 2개 이상에서 근거를 받은 페이지 비율 | 같은 업무 원본을 넣을수록 올라가야 함 |
| 스텁비율 | 본문 근거 표기가 2개 미만인 빈약한 페이지 비율 | 낮을수록 |
| 확인필요페이지비율, 미해결질문 | 아직 풀리지 않은 불확실성 | 검수·질문으로 줄여야 함 |

이 지표들은 **구조의 건강 상태**만 본다. 위키가 실제로 쓸모 있는지는 팀 질문 목록(competency question)으로 답해보는 테스트로 따로 확인한다.
